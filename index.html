Ejercicio de try / catch / finally con fetch
Escribe un usuario de GitHub y presiona Buscar. Prueba con leonmiguel2622 (válido) o @leonmiguel2622 (con @ para forzar error 404).
Consola de ejecución (log)
> Listo. Ingresa un usuario y haz clic en Buscar. > El bloque try hará el fetch, catch atrapará errores (404, red, validación de @) y finally siempre se ejecutará.

📘 ¿Cómo funciona el try / catch / finally aquí?

  • try: valida el input y hace await fetch(`https://api.github.com/users/${username}`). Si response.ok es false, lanza throw new Error.
  • catch: captura errores de validación (vacío, contiene @), errores HTTP 404 y fallos de red. Muestra mensaje rojo sin romper la app.
  • finally: siempre ejecuta log("Búsqueda finalizada (bloque finally ejecutado).") y restaura el botón, haya éxito o error.
